# 日历与交互更新 · v6.5.0

## 入口与功能

短期任务 → 日历安排。桌面默认月视图，手机默认日视图，可切换月 / 周 / 日。

- 日期旁的加号或周 / 日视图的空白时段可新建任务。
- 支持开始日期、结束日期、起止时间和全天安排；可跨日。
- 任务时间重叠时提示，但允许保存。
- 日历与今日任务共用原有任务记录、完成状态、属性和经验；不会复制出第二个任务。
- 尚未到安排日期的任务只在日历展示；开始日期到来后进入今日任务，未完成则继续保留。
- 原有截止日期与日历安排分别保留。移除时间安排不删除任务。
- 已完成任务可以改名称和时间；为避免经验账不一致，需恢复未完成后才能改属性与经验。
- 本版是站内日历，不包含飞书同步、重复日程、拖拽改期或关闭网页后的到点通知。

## 交互与样式

- 保留 Dashboard 信息展示用途、原属性选择、独立日 / 周 / 月榜及复盘位置。
- 页面恢复上次子页与浏览位置；未读委托不再强制改变短期任务的落点。
- 记录练习与设为今日重点成为两个独立操作。
- 撤销上次只删除当天最近一条手动练习；清空手动记录需确认，任务关联记录保留。
- 补录期间显示日期提示；目标名称可行内修改，Enter 保存、Escape 取消。
- 输入中的添加表单在全局刷新时保留草稿和焦点。
- 统一卡片、标题、Tab、按钮、正文与说明字号；手机日历在组件内部滚动。

## 统计边界

旧版统计只存在实际使用浏览器的 localStorage，未包含完整子页与操作覆盖。不能把缺失数据解释为低频或未使用。

新版保留旧累计次数，新增按天的近 90 天计数与近 14 天汇总，补充短期任务子页、榜单子页、日历操作与练习记录计数，并支持导出。历史日期不回填。本次未读取到用户 Chrome 的真实统计，因此未据此删减功能。
