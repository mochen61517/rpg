# v6.6.0：信息层级与操作路径

- 年度目标以标题、下一步和实际步骤进度为主要内容；累计投入估算仅保留在详情。下一步可安排到日历，取消不创建任务。目标名称不限修改次数，并保留修改历史。
- 本月计划采用单列主视图。实际推进、复盘和状态放入月末回顾；过去和未来月份保留原有数据及编辑能力。
- 未完成任务按逾期、今天、之后、无日期分组，支持属性筛选和原有排序。日期安排与截止日独立编辑。
- 习惯和补剂默认只展示打卡，管理模式显示添加、编辑和删除，属性与经验字段保留。
- 进行中视图集中展示未完成 NPC 委托和已接榜任务；完成任务折叠。日、周、月榜任务池保持独立。
- 生活碎片支持关键词和月份筛选，默认显示最近 12 条；历史与回顾降为次级入口，周报/月报保留在展开区。
- 设置优先展示本机存档状态及恢复点，导出单独保留；导入、文件连接和详细说明折叠。
- 修复年度存档迁移丢弃附加字段的问题，保留进展记录、附件、下一步、任务关联及名称修改历史。

验证：calendar、clarity、settings、hierarchy 四组测试；桌面与 390px 手机示例页面检查；完整应用初始化无控制台错误。测试和预览使用示例数据，不包含用户存档。
