### 发现的问题（已交叉验证）
1. **主题切换按钮实际不生效（确定性：已验证）**。`applyTheme()`(5419 行) 设的是 `documentElement.setAttribute('data-theme', k)`，但 76 条主题覆盖规则全是 `html.theme-bing` / `html.theme-dark` **类选择器**，全文 `[data-theme` 选择器数量为 **0**，也没有任何 `classList.add('theme-…')`。→ 点「丁火·清凉」「命理·夜」只会切换按钮高亮 + 写入 `S.theme`，页面样式不变。修法：改成 `classList` 切换，或把 CSS 选择器改为 `html[data-theme=...]`。
2. **`itemXp` / `weightedXp` 各重复定义两次**（1831/1832 与 1841/1842），函数提升导致后者覆盖前者；后者用 `it.min` 而非日期化的 `it.mins[d]`。所幸**全部调用点用的都是 `itemXpAt`/`weightedXpAt`**，这 4 个函数是死代码，无实际 bug，但应删掉防止误用。
3. `start_server.bat` 路径失效（见上）。
4. 隐私：`PAGE_PWD_DEFAULT`(1672 行) 明文口令 + 愿望/兴趣/猫照/头像/iHour 时长仍硬编码在公开仓库文件里；资产已在 v5.12.3 移出（`ASSETS_TEMPLATE` 占位）。pushplus token 只走 `S.pushToken`（localStorage），未硬编码 ✓。
5. 灵宠仍是静态展示（角色设定页两张猫照 + 江湖轶事「灵宠」分类任务），无独立成长系统 —— 与历史记录一致。
