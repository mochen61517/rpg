## life-rpg 使用约定：填写数据走 GitHub 链接，不要 file:// 双击
- 用户问"填写数据最好本地文件夹打开还是 github 链接"。
- 结论：固定用 github 链接（或本地 localhost 服务）录入与访问，**不要 `file://` 双击本地 html**。
- 原因两条硬约束：
  1. localStorage 按 origin 隔离：`file://` 与 `mochen61517.github.io` 是两个独立 origin，数据不互通，来回切会丢/看不到旧数据。
  2. 自动备份的"本地 save.json 落盘"用 File System Access API（`showSaveFilePicker`），只在 https/localhost 可靠工作，`file://` 下 Chrome 基本禁用 → 备份兜底失效。
- 实操：固定一个 origin 用到底；首次进「⚙️ 数据&设置」点「📁 选择存档文件」授权一次本机 save.json（仅 https 下成功）；换设备/清缓存用「📂 导入存档」恢复。
